# 🖐️ HandiView – A Gesture-Based Human-Computer Interface

**HandiView** is a cross-platform hand-tracking interface designed for gesture-based interaction with digital content, emphasizing accessibility, AR/VR integration, and intuitive control.

It started as a **Python desktop app** and evolved into a **web-based platform**, demonstrating real-time hand detection, gesture recognition, and 3D interaction.

---

## 🌟 Why "HandiView"?

The name *HandiView* combines:
- **"Handi"** – short for *hand interface*, and a nod to *handicap accessibility*
- **"View"** – real-time visual feedback and interaction

HandiView aims to bridge gesture recognition and accessible interaction design, benefiting users with motor impairments or those in sterile environments.

---

## 🔧 Project Versions

### 🖥️ Desktop Version (Python + OpenCV + MediaPipe)

**Features:**
- Real-time hand tracking with 21-point landmarks
- Basic gesture recognition (pinch, fist, etc.)
- 3D object interaction using Pygame/OpenGL

**Tech Stack:**
- Python
- OpenCV
- MediaPipe
- Pygame / PyOpenGL

### 🌐 Web Version (JavaScript + MediaPipe JS + Three.js)

**Features:**
- Browser-based hand tracking (no install)
- Cross-platform & mobile-compatible
- 3D object interaction using Three.js

**Tech Stack:**
- JavaScript
- MediaPipe Hands JS
- Three.js

---

## ♿ Accessibility & Impact

HandiView supports:
- Touchless interaction in sterile/public environments
- Gesture-based control for people with limited mobility
- AR/VR natural hand interfaces (future integration)
